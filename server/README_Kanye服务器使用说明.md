# Kanye · 《长空·1951》跨网联机服务器（中继）

这是游戏自带、**纯 C、零依赖**的 UDP 中继服务器。它解决一个问题：不在同一个
WiFi/局域网里的两台设备（比如你和外地朋友），怎么一起联机。

整体链路：

```
你的电脑/手机(主机) ──frpc──▶ frps穿透节点(公网) ◀──frpc/直连── 朋友的电脑/手机
                                   ▲
                          Kanye 中继跑在能被公网访问到的机器上
```

> 更简单的理解：Kanye 是“聚会点”，frpc 负责把你家里/手机上的 Kanye 暴露到公网。
> 你需要自己有一台公网服务器，或在 chmlfrp 这类 frp 面板上开一条 **UDP 隧道**。

---

## 一、文件说明

| 文件 | 作用 |
|---|---|
| `Kanye.exe` | Windows 版中继（已编译，直接运行） |
| `Kanye` | Linux / Android(Termux) 版中继（已编译） |
| `frpc.ini` | frpc 配置模板，需要填你自己穿透面板给的地址和 token |
| `etcioad.txt` | 只写一个数字：固定开第几场战役（默认 `1`，范围 1~27） |
| `kanye.c` / `build_server.sh` | 源码与一键编译脚本 |

## 二、启动（和游戏命令一致）

Windows（先开中继，再开 frpc）：

```bat
Kanye.exe 24463 & frpc -c frpc.ini
```

Linux / 安卓 Termux：

```bash
chmod +x Kanye frpc
./Kanye 24463 & ./frpc -c ./frpc.ini
```

`24463` 是中继监听的 UDP 端口，可自定义，但要和 `frpc.ini` 里的 `localPort`
保持一致。启动后窗口会实时打印中文日志：谁在发现、谁开了主机、谁加入、谁开局、
当前在线人数。

## 三、配置 frpc.ini

在穿透面板（例如 chmlfrp）创建一条 **UDP** 隧道，把面板给的信息填进来：

```ini
serverAddr = 你的节点域名或IP
serverPort = 面板给的frps端口
auth.token = 面板给的访问密钥
[[proxies]]
name = "kanye1951"
type = "udp"
localIP = "127.0.0.1"
localPort = 24463
remotePort = 24463
```

## 四、游戏里怎么连

**主机（开房的人）**
1. 主菜单 → `⑨ 联机作战` → `④ 远程服务器`；
2. 第一次点 `+ 添加新服务器`，名字随便填，地址填 `隧道域名或公网IP:远程端口`
   （例如 `123.234.1.2:24463`）；
3. 回到列表点一下这行设为当前（前面变 `●`），点 `用当前服务器创建主机`；
4. 主机界面**左上角会显示穿透地址**，把它发给队友。

**队友（加入的人）**
1. 同样进 `④ 远程服务器` → `+ 添加新服务器`，填主机给的地址；
2. 列表会自动刷新在线状态和延迟（ms）；
3. **双击（手机快速点两下）这一行**即可进入，等待主机开战。

局域网（同一 WiFi/热点）不需要以上任何东西，直接用 `③ 搜索并加入主机`。

## 五、etcioad.txt 固定战役

文件里只放一个数字 `1`~`27`，对应游戏里战役卡片的显示编号。设好后，无论主机
选哪一场，Kanye 都会把开局统一成这一场，适合公开服务器固定开黑。删掉内容或写
`0` 即关闭强制、由主机选择。

## 六、重新编译

```bash
bash build_server.sh
```

需要 mingw 才会同时产出 `Kanye.exe`；只编 Linux 版用 `cc -O2 -o Kanye kanye.c`。
